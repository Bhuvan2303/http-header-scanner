# HTTP Security Header Scanner

A Python-based web security tool that analyzes HTTP response
headers and checks for important security controls.

## Features

- Checks HTTP response status
- Checks security headers
- Reports missing headers

## Security Headers

- Strict-Transport-Security
- Content-Security-Policy
- X-Content-Type-Options
- X-Frame-Options

## Technologies

- Python
- HTTP
- HTML

## How It Works

User enters a URL
        ↓
Backend sends HTTP request
        ↓
Response headers are collected
        ↓
Security headers are checked
        ↓
Results are returned

## Disclaimer

Only scan websites you own or have permission to test.
